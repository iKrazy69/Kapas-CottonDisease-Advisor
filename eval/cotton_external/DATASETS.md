# Datasets used in the outside-photo tests

Facts about the sources come from each dataset's own page or paper as read on 22 Nov 2026. "Not checked" means the page was not read for that item: do not quote it before checking. Counts under "found here" are measured on the files in `Downloads/Cottondataset` and the project's Drive zips.

| Dataset | Source and licence | What the authors say it holds | Found here (files) | What we did with it |
|---|---|---|---|---|
| **Project's own photos** ("Cotton Data set Man Mohan") | Source: **not filled in yet** (ask the team). Licence unknown. | 8 folders: Anthracnose, Bacterial leaf blight, Boll rot, Cotton leaf curl virus, Healthy, Myrothecium leaf spot, Root rot, Sooty mould. | 614 files in two Google Drive zips (`...184005Z-1-001/002`), 8 of them empty (0 bytes). Median size 6720 x 4480 px. The 296-photo folder is a partial first export: 281 distinct non-empty files, all inside the 614. | Training data of the saved model (368 train / 80 validation / 81 test after removing 70 + 7 files). ## Class mapping

| App class | Matched by |
|---|---|
| Bacterial leaf blight | "Bacterial blight" in East West, Severity, Ayaz, SAR-CLD; the project's own class |
| Cotton leaf curl virus disease | "curl virus" in Severity and SAR-CLD; the project's own class |
| Healthy Plants | "Healthy", "Healthy Leaf" in East West, Severity, Ayaz, SAR-CLD; the project's own class |
| Anthracnose, Myrothecium leaf spot, Sooty mould | No outside counterpart; only the project's own photos |
| Never seen by the classifier | Alternaria leaf spot, Fusarium wilt, Verticillium wilt, target spot, powdery mildew, aphids, army worm, herbicide damage, jassid, leaf reddening, leaf variegation, cotton boll rot and green cotton boll (boll photos, not leaves), the project's Boll/Root rot |

Labels are the authors'; no cotton expert has checked them. Names such as "Bacterial blight" and "Bacterial leaf blight" are assumed to be the same disease.
